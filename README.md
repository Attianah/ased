# Ased

Shop for phones, computers, tablets, watches, chargers, and other electronics.

## Run locally

Requires Node.js 22.

```bash
npm install
npm run dev
```

Open the site, then go to `/manage` to sign in and claim the shop. Only that account can edit products and categories.

## Shoppers

Browse the shop, add items to the cart, and send the full order to WhatsApp. Payment is by Telecel Cash. Free delivery inside Accra applies to phones and laptops. Other items, or delivery outside Accra, are paid separately or collected on the GCTU campus.
